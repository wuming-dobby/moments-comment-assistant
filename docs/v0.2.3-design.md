## 一、根因与证据（不变）

微信 4.x：进程 `Weixin.exe`、窗口类名 `Qt51514QWindowIcon`；代码写死 `WeChatMainWndForPC`（`capture.py:10`）→ 命中 0。PrintWindow(PW_RENDERFULLCONTENT) 本机实测成功（mean 220.5／stddev 73.2）。

两条独立缺陷：找不到窗（类名）；找到了也没反馈（无托盘、启动即隐藏）。附带：配置落 `_MEIPASS`（`vision.py:9`）、GDI 截图不可靠（`capture.py:40-46`）。

## 二、最终函数契约（实现必须照此）

```python
# src/paths.py
APP_DIR: Path                      # %APPDATA%\MomentsAssistant
def ensure_dirs() -> None          # 建 APP_DIR 与 APP_DIR\screenshots

# src/capture.py
def resolve_target(*, use_cache=True) -> int | None            # 前台微信窗 → 最大可见微信窗 → None
def find_wechat_window(*, enum_windows=None, proc_name_of=None,
                       foreground_hwnd=None, class_of=None) -> int | None
def crop_client(img, wr, cr, c0) -> "PIL.Image.Image"          # 纯函数，越界 ValueError
def is_invalid(img) -> tuple[bool, dict]                        # 纯函数，黑/白/无内容
def capture_wechat(hwnd=None, out_dir=None) -> Path             # PrintWindow → crop → 判无效 → BitBlt 降级

# src/vision.py
def load_config() -> dict           # 字段级合并：env > APP_DIR\config.json > 旧 config.json
def generate_comment(image_path: str) -> str

# src/overlay.py
class Overlay: always_visible: bool; pinned: bool; suppress... 无
def wechat_is_foreground() -> bool  # 前台窗进程名 ∈ 微信集合 且 非最小化

# src/main.py
def main() -> None                  # ensure_dirs → DPI → 单实例(Local\ mutex + QLocalServer) → 托盘 → app.exec_()
```

## 三、验收断言

## 四、测试矩阵
